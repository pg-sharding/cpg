# GIN scan-key layout control: complete r1/r2 comparison

The source and ABI result is verified: the same one-field reorder makes the no-memo key 144 bytes (C) and the existing memo key 152 bytes (K4) on the target LP64 ABI. **These measurements do not establish a general speedup from the reorder or a fix for dense overhead.** All positive, negative and control outcomes are supplied separately for two complete attempts.
