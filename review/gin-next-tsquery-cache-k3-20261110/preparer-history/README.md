# K3 source/replay publication scaffold

This is a LOCAL preparer snapshot, not the final publication or a performance
report. Actual source/core/build/SQL/native/budget gates and zero-accepted smoke
passed on VM158; accepted timing collection,independent arithmetic,final live
release and final root freeze/publication are pending.

`source/` contains the canonical standalone K3 alternative and K1 reference.
`reference-inputs/` contains the63 exact original immutable text inputs;
`actual-compact-evidence/` contains real build/gate/smoke/review receipts.
`SOURCE-PROVENANCE.json` binds revisions and hashes. `source-review/` retains
callback/lifetime/prior-art review and bounded archive evidence. Original
historical prelaunch statuses remain historical inside the copied inputs.

`REPRODUCE.md` gives source/setup/build→qualification→prepare→smoke→external
review→run→analysis commands in a new namespace. `replay.py` is a new staged
frontdoor using original controllers and newly generated receipts; it has not
been executed for a Linux build or replay. There are no substituted old ELFs,
headers,support libraries or PGDATA, and no weakened source/case pins.

A owns actual numeric/report collection. `ARTIFACT-REQUIREMENTS.md` lists the
remaining final artifacts. The English UNSENT draft has real completed gate
facts and the separately labelled K1 prior result,without invented K3 timing.
Nothing is mailed,pushed or uploaded by this scaffold.
