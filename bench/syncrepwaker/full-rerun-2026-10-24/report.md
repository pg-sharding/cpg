# Full rerun: does the separate synchronous replication waker help?

`base` is pristine MDB; `current-off` is P1 with the waker disabled. `off`, `on` and `hybrid8` use the same combined P1+P2+P3 postgres binary: direct wakeups, full delegation (limit 0), and hybrid direct-prefix wakeups (limit 8). P2 and P3 do not delegate or notify a waker when it is disabled.

The main comparison is the same candidate binary with the waker enabled versus `off`. Each summary cell shows **Δ TPS / Δ p50 / Δ p99**. Positive TPS and negative latency are improvements. Values are medians of per-run metrics; fixed-rate response time includes scheduling lag. Saturation cases can achieve different throughput. Observed run ranges are descriptive, not confidence intervals.
